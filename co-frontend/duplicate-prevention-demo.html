📋 Test Scenarios

✅ Scenario 1: Valid First Registration

Use any test Aadhar (e.g., 123456789012) with matching email. Should succeed.

❌ Scenario 2: Duplicate Registration

Try to register the same Aadhar twice. Second attempt should fail.

❌ Scenario 3: Cross-Registration

Register as voter, then try to register as candidate with same Aadhar. Should fail.

❌ Scenario 4: Invalid Aadhar

Use non-existent Aadhar number. Should fail validation.

❌ Scenario 5: Email Mismatch

Use valid Aadhar with wrong email. Should fail validation.
